autoSocial Poster

A personal automation tool that publishes a shop owner’s own product videos and photos to their own connected social accounts.

What it does

The operator drops a video or photo into a folder in their own Google Drive and names the file with a short brief. The tool then drafts a caption, adds the shop’s hashtags, and posts the file to the accounts the operator has connected — including their own TikTok account through the official TikTok Content Posting API.

How a post happens

  1. The operator adds a media file to their intake folder.
  2. The tool reads the file, drafts a caption, and writes it to a Google Sheet.
  3. The tool uploads the file and posts it to each connected account.
  4. The resulting post link is written back to the sheet.

Scope of access

For TikTok, the tool uses only the video.upload and video.publish permissions, plus a one-time read of creator info that the Content Posting API requires. It does not read messages, followers, or analytics, and it stores its working data in the operator’s own Google account rather than on any server we run.
